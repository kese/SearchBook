SearchBook 사용법
=================

1. SearchBook.exe를 더블클릭합니다.
2. EM 또는 WM 등록번호가 들어 있는 .xlsx/.txt/.csv 파일을 창에 끌어 놓습니다.
3. 불러온 건수를 확인한 뒤 "조회 시작"을 누릅니다.
4. 완료된 Excel은 SearchBook.exe 옆 results 폴더에 자동 저장됩니다.

입력 예시
---------
등록번호
EM00510342
WM00000001

중요
----
- 처음에는 5~10건으로 시험해 주세요.
- 기본 요청 간격 0.7초를 권장합니다.
- 조회를 중지해도 완료된 내용은 Excel로 저장됩니다.
- 50건마다 자동저장되므로 장시간 작업 중에도 중간 결과가 남습니다.
- 사이트에서 일치 행을 찾지 못해도 로컬 전체목록에 정확한 등록번호가 있으면 전체정보를 표시합니다.
- "미확인"은 사이트와 로컬 전체목록 모두에서 정확한 등록번호를 찾지 못한 경우입니다.
- "오류"는 네트워크 또는 서버 요청이 재시도 후에도 실패한 경우입니다.

결과 열
-------
입력순번, 등록번호, 조회결과, 도서상태, 반납예정일/기한, 소장위치,
청구기호, 서명, 저자, 출판사, 출판년, ISBN, 최종변경일, 서지정보,
상세URL, 정보출처, 처리메시지, 조회시각

지원 환경
---------
Windows 10/11, .NET 10 Desktop Runtime
