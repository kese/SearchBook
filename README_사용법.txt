SearchBook 사용법
=================

1. SearchBook.exe를 더블클릭합니다.
2. EM 또는 WM 등록번호가 들어 있는 .xlsx/.txt/.csv 파일을 창에 끌어 놓습니다.
3. 불러온 건수를 확인한 뒤 "조회 시작"을 누릅니다.
4. 완료된 Excel은 %LocalAppData%\SearchBook\results 폴더에 자동 저장됩니다.
5. 앱의 "도구 > 결과 폴더 열기"로 저장 위치를 바로 열 수 있습니다.

입력 예시
---------
등록번호
EM00510342
WM00000001

중요
----
- 처음에는 5~10건으로 시험해 주세요.
- 기본 요청 간격 0.7초를 권장합니다.
- 조회를 중지해도 완료된 내용은 Excel로 저장됩니다.
- 50건마다 자동저장되므로 장시간 작업 중에도 중간 결과가 남습니다.
- "작업 재개"에서 기존 SearchBook 결과 Excel을 선택하면 미완료 행만 이어서 조회합니다.
- 결과 검색, 대기/조회중/성공/실패 필터, "실패 재조회"로 필요한 행만 검토할 수 있습니다.
- 결과 표의 "조회결과"와 "도서상태"는 실시간 확인 상태에 따라 색상으로 구분됩니다. 조회결과 셀에 마우스를 올리면 WM 기준 비교 세부사항을 볼 수 있고, 필터에서 "WM 일치" 또는 "WM 불일치"를 선택할 수 있습니다. 저장 Excel에는 기준 비교 상태와 세부사항이 별도 열로 남습니다.
- 파일 없이 등록번호를 복사한 뒤 "붙여넣기"로 바로 불러올 수 있습니다.
- 사이트에서 일치 행을 찾지 못해도 로컬 전체목록에 정확한 등록번호가 있으면 전체정보를 표시합니다.
- "성공"은 도서관 서버 또는 로컬 전체목록에서 정확한 등록번호를 확인한 결과입니다.
- "실패"는 사이트와 로컬 전체목록 모두에서 정확한 등록번호를 찾지 못한 경우입니다.
- 실제 조회 기준은 "정보출처" 열에서 실시간 조회와 로컬 전체목록으로 구분합니다.
- `wm00010000-300000.xls` 기준 파일은 실제 WM `WM00010000`~`WM00030000` 행을 비교에 사용합니다. 실시간 조회 실패는 "실시간 미확인", 기준 파일에 행이 없으면 "기준 없음"으로 표시합니다.
- 웹 소장위치는 "중앙도서관 / 보존서고"처럼 지점명과 자료실명을 함께 표시합니다.
- 네트워크 또는 서버 요청이 재시도 후에도 실패하면 조회결과는 "실패"로 표시되고 원인은 처리메시지에 남습니다.

단축키
------
Ctrl+O 파일 선택, Ctrl+Shift+O 작업 재개, Ctrl+Shift+V 붙여넣기,
Ctrl+Shift+R 실패·대기 재조회, Ctrl+F 결과 검색, Esc 조회 중지

결과 열
-------
입력순번, 등록번호, 조회결과, 도서상태, 반납예정일/기한, 소장위치,
청구기호, 서명, 저자, 출판사, 출판년, ISBN, 최종변경일, 서지정보,
상세URL, 정보출처, 기준 Excel 비교, 기준 비교 세부사항, 처리메시지, 조회시각

지원 환경
---------
Windows 10/11, .NET 10 Desktop Runtime
