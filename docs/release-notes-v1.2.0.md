# SearchBook v1.2.0

## 전체 도서정보 보완

- 2026-08-06 기준 EM 69,685건 전체목록을 번호대별 로컬 카탈로그로 반영했습니다.
- `제적`, `소재불명`, `소재불명 확인요청중`, `파손자료`처럼 사이트 소장정보에서 누락되기 쉬운 도서도 정확한 등록번호가 있으면 조회합니다.
- 로컬 카탈로그가 도서상태뿐 아니라 소장위치, 청구기호, 서명, 저자, 출판사, 출판년, ISBN, 최종변경일을 제공합니다.
- 원격 조회가 성공하면 현재 도서상태와 반납기한을 우선하고, 비어 있는 서지정보만 로컬 전체목록으로 보완합니다.
- 원격 조회가 실패해도 로컬 전체목록에 정확히 일치하는 등록번호가 있으면 전체정보를 결과에 기록합니다.
- 결과 화면과 Excel에 저자, 출판사, 출판년, ISBN, 최종변경일, 정보출처 열을 추가했습니다.
- 등록번호, ISBN, 최종변경일은 Excel에서 숫자 변환이나 과학적 표기가 발생하지 않도록 텍스트 서식을 적용했습니다.

## 정확성 경계

- 포함된 원본에는 WM 행이 없으므로 EM의 숫자 부분을 WM에 재사용하지 않습니다.
- 로컬 상태는 2026-08-06 스냅샷이며, 원격에서 현재 정보가 확인되면 원격 값을 우선합니다.

- 전체 9개 자동화 테스트 통과
- 실제 도서관 조회 `EM00510342` 성공
