# SearchBook v1.2.1

## 정제된 EMR 작업 화면

- 기본 제목표시줄을 제거하고 이동·크기 조절·최소화·최대화·닫기가 가능한 42px 맞춤 제목표시줄을 적용했습니다.
- 밝은 청회색 EMR 스타일, 조밀한 결과 레코드 표, 얇은 진행 표시와 절제된 상태 색상으로 화면을 전면 재구성했습니다.
- 불필요한 화면명, 작업 순서, 문맥, 처리 모드, LOCAL 배지와 01·02 장식 번호를 제거해 작업 영역을 넓혔습니다.
- 제목표시줄에는 투명 고해상도 고양이 에셋을 사용합니다.

## 조회 진행과 Windows 전송 모션

- 완료 건수, 성공, 미확인, 남은 시간, 분당 처리 속도와 이동 그래프를 실시간으로 표시합니다.
- 조회 시작 버튼은 대기 중 Windows 재생 글리프를 표시하고, 조회 중에는 현재 Windows의 기본 폴더·문서 아이콘을 이용한 파일 전송 모션으로 전환됩니다.
- 버튼 내부 좌우 안전 여백을 확보해 고해상도 배율에서도 폴더 아이콘이 잘리거나 눌리지 않게 했습니다.
- 조회 완료 알림을 비모달 시스템 소리로 바꿔 결과 검토 흐름을 막지 않습니다.

## Excel 편의 기능

- 조회 중에도 현재 결과를 별도의 고유한 Excel 스냅샷으로 만들어 바로 열 수 있습니다.
- 자동 저장이 사용하는 원본 결과 파일은 Excel 잠금과 충돌하지 않습니다.
- 완료 후에는 최종 결과 파일을 기본 Excel 앱으로 바로 엽니다.

## 예제와 검증

- 로컬 전체 도서정보에서 추린 서로 다른 등록번호 50개의 `input_sample_50.txt`를 포함했습니다.
- 자동화 테스트 10개를 모두 통과했습니다.
- self-contained Windows x64 배포본에서 50개 예제 로딩과 실제 WPF 창 표시를 확인했습니다.
