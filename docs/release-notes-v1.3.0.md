# SearchBook v1.3.0

## 장시간 작업 안전성

- 조회 중 창 또는 트레이에서 종료해도 현재 요청을 중지하고 완료된 결과 저장이 끝난 뒤 닫습니다.
- 결과, 작업 중 미리보기, 업데이트, 진단 파일을 `%LocalAppData%\SearchBook` 아래에 분리했습니다.
- 작업 중 미리보기는 7일이 지나면 시작 시 자동 정리합니다.
- 오래된 SearchBook 결과 Excel을 `작업 재개`로 불러와 미확인·중지 행만 이어서 조회합니다.

## 결과 검토와 입력 편의

- `실시간 확인`, `로컬 스냅샷`, `미확인` 상태를 구분해 정보의 기준을 명확히 표시합니다.
- 등록번호·서명·저자·상태 검색, 결과 상태 필터, 미확인 행만 재조회를 추가했습니다.
- 반납기한, 최종변경일, 조회시각, 상세 페이지 열기를 결과 표에서 바로 확인할 수 있습니다.
- 클립보드 붙여넣기와 스캔 값·중복 제거 건수 요약을 추가했습니다.
- 기존 결과를 새 입력으로 바꾸기 전에 확인하고, 동시에 시작된 오래된 파일 읽기가 최신 결과를 덮지 못하게 했습니다.

## 접근성과 운영

- 파일 선택 영역을 키보드로 동작하는 버튼으로 바꾸고 명확한 포커스 링과 자동화 이름을 적용했습니다.
- `Ctrl+O`, `Ctrl+Shift+O`, `Ctrl+Shift+V`, `Ctrl+Shift+R`, `Ctrl+F`, `Esc` 단축키를 제공합니다.
- 주요 상태를 스크린리더에 정중한 라이브 영역으로 알립니다.
- `도구` 메뉴에서 결과 폴더 열기, 개인정보를 제외한 진단 정보 저장, 업데이트 확인을 실행합니다.

## 보안과 검증

- 비정상적으로 크거나 압축률이 높은 XLSX와 외부 엔터티 XML을 차단합니다.
- 상세 링크는 HTTP/HTTPS만 열고 진단 보고서에는 등록번호·서지정보·URL을 기록하지 않습니다.
- 서비스 회귀 테스트 16개, Release 빌드, 실제 2건 조회·LocalAppData 결과 저장, 50건 고배율 WPF 화면을 검증했습니다.
