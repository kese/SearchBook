# SearchBook v1.3.1

## 더 직관적인 조회결과

- 조회결과를 `대기`, `조회중`, `성공`, `실패` 네 상태로 통일했습니다.
- 실제 데이터 기준은 별도 `정보출처` 열에서 도서관 실시간 조회와 로컬 전체목록으로 구분합니다.
- 기존 결과 Excel의 `실시간 확인`, `로컬 스냅샷`, `미확인`, `오류`, `중지됨` 상태를 새 상태 체계로 안전하게 변환합니다.
- 알 수 없는 이전 상태는 `실패`로 정규화하여 다섯 번째 상태가 화면에 나타나지 않도록 했습니다.

## 지점이 명확한 소장위치

- 웹 소장정보의 지점 헤더와 자료실을 결합해 `중앙도서관 / 보존서고` 형식으로 표시합니다.
- 중앙도서관, 증평도서관, 의왕도서관의 같은 이름 자료실을 결과에서 구별할 수 있습니다.
- 이미 지점이 포함된 값은 중복으로 붙이지 않습니다.

## 화면 가독성

- 우측 하단의 `WIN-X64`를 실행 중인 앱 버전으로 바꿔 이번 릴리스에서는 `v1.3.1`을 표시합니다.
- 입력 요약을 한 줄에 맞게 축약했습니다.
- 긴 서명은 말줄임표로 표시하고 전체 값은 툴팁으로 확인할 수 있습니다.

## 검증

- 서비스 및 회귀 테스트 18개를 통과했습니다.
- Release 빌드와 실제 도서 1건 조회를 완료했습니다.
- 실제 화면에서 `성공`, `중앙도서관 / 자료실`, `v1.3.1` 표시를 확인했습니다.
