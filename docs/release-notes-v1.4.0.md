# SearchBook v1.4.0

## WM 기준 Excel 비교

- `docs\wm00010000-300000.xls`를 WM 기준 원본으로 추가했습니다.
- 배포본은 Excel 설치 없이 동작하도록 원본에서 변환한 `wm00010000-300000.xlsx`를 자동으로 읽습니다.
- 실시간 조회가 성공하면 도서상태·소장위치·청구기호·서명과 양쪽에 값이 있는 서지 항목을 기준 행과 대조합니다.
- 저장 Excel에 `기준 Excel 비교`, `기준 비교 세부사항`을 남깁니다.
- `일치`, `불일치`, `부분 확인`, `실시간 미확인`, `기준 없음`, `비교불가`를 구분하며 불일치 시 기준값과 조회값을 함께 기록합니다.
- 결과 표에서는 `조회결과`와 `도서상태`를 실시간 상태별 색상으로 구분하고, 조회결과 셀 툴팁과 `WM 일치`·`WM 불일치` 필터로 기준 비교를 확인할 수 있습니다.

- 원본 `Sheet1`은 19,373행·14열이며 유효 WM 등록번호는 19,372건입니다.
- 실제 유효 범위는 `WM00010000`~`WM00030000`입니다. 파일명에 포함된 `300000`까지의 행은 현재 원본에서 확인되지 않았으므로 기준 없음으로 처리합니다.
- 상태 분포는 `대출가능` 17,690건, `대출불가` 612건, `소재불명` 566건, `제적` 480건, `대출중` 17건, `파손자료` 7건입니다.
